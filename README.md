# driving-school-pro 🚗

מערכת ניהול שיעורי נהיגה — בית ספר לנהיגה ברוך תור

## קבצים

| קובץ | תפקיד |
|------|--------|
| `setup.gs` | יצירת מבנה הגיליונות — **מריצים פעם אחת בלבד** |
| `students.gs` | הוספה וחיפוש תלמידים |
| `calendar_sync.gs` | שאיבת שיעורים מגוגל קלנדר |
| `payments.gs` | רישום תשלומים ושליפת יתרות |
| `triggers.gs` | הגדרת טריגר לילי אוטומטי |

## גיליונות
- **תלמידים** — רישום תלמידים
- **שיעורים** — היסטוריה (ממולא אוטומטית מקלנדר)
- **תשלומים** — רישום תשלומים ידני
- **יתרות** — חישוב חוב אוטומטי (נוסחאות)

## סדר הפעלה ראשונית
1. צור Apps Script project חדש מתוך ה-Sheet
2. העתק את כל קבצי ה-.gs
3. הרץ `setupSheets()` מתוך `setup.gs`
4. הרץ `setupTriggers()` מתוך `triggers.gs`
5. אשר הרשאות גישה לקלנדר ולמייל

## קלנדר
הסקריפט סורק את הקלנדר הראשי.
שיעורים מזוהים לפי **שם התלמיד** (חייב להיות זהה לשם בגיליון תלמידים).
במקרה של שם כפול — תגיע התראה במייל לזיהוי ידני.
